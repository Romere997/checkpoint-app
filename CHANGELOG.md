# Changelog

## 0.1.0 — 2026-08-08 (initial release)

- FastAPI server with SQLite persistence
- REST API: create/list/get/answer checkpoints + stats
- Phone PWA: dark UI, yes/no verify, approve with custom options, reason prompt
- Live polling (12s), pending queue badge, History tab with follow-through ring
- Agent SDK: `ask_human()` (blocking) + `ask_human_async()` + `check_answer()`
- PWA manifest + icon — installable to iPhone home screen
- Auth via `X-API-Key` header
- Deployable on Render / Railway / Fly
